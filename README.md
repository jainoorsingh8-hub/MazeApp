🧩 Maze Solver & Generator
An interactive web application that generates random mazes and visualizes how different pathfinding algorithms solve them in real time. The project demonstrates the working of Depth-First Search (DFS), Breadth-First Search (BFS), and A* Search algorithms with animated exploration, shortest path visualization, and performance metrics.

🔗 Live Demo: https://maze-ks22.onrender.com/
